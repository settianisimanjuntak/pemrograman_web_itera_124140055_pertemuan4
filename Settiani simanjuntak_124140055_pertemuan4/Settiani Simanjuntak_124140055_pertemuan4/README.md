## Deskripsi Program

| Berkas | Deskripsi |
|--------|-----------|
| `tugas1_bmi.py` | Meminta berat (kg) & tinggi (m), menghitung `BMI = berat / (tinggi * tinggi)`, lalu menentukan kategori (kurang / normal / berlebih / obesitas) dengan `if-elif-else`. Dilengkapi validasi input. |
| `tugas2_nilai_mahasiswa.py` | List berisi 6 dictionary mahasiswa. Menghitung nilai akhir (30% UTS + 40% UAS + 30% Tugas), menentukan grade A-E, menampilkan tabel, serta mencari nilai tertinggi & terendah. |
| `math_operations.py` | Modul: konstanta `PI`, luas & keliling (persegi, persegi panjang, lingkaran), konversi suhu Celsius ke Fahrenheit dan Kelvin. |
| `main.py` | Program utama yang mengimpor `math_operations` dengan 2 cara (`import ... as mo` dan `from ... import ...`) dan memakai seluruh fungsinya. |

## Cara Menjalankan

```bash
python tugas1_bmi.py
python tugas2_nilai_mahasiswa.py
python main.py
```

(Gunakan `python3` jika `python` tidak dikenali.)
